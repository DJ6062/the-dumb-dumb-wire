# Hey! Dumb Dumb — The Wire (static site)

Free, backend-less site hosted on **GitHub Pages**. No sign-ins. The only
user input is the newsletter "join" form, which posts to a third-party mail
provider (we never store emails ourselves).

## Layout
- `index.html` — the site; fetches `feed.json` (same-origin) and renders stories
  with Right / Neutral / Left takes.
- `feed.json` — the newsletter feed the **Room Rummy Discord bot** polls every
  5 min and posts to `#room-rummy-builds`. Regenerated by `build_feed.py`.
- `feed_contract.md` — the exact feed.json shape the bot expects.

## Publishing a story
1. Run `build_feed.py` (in `rummy-bot/newsletter-feed/static/`, or copy it here):
   ```bash
   python build_feed.py --add --topic politics \
     --title "HEADLINE" --url "https://.../story/x" --summary "..." \
     --right "Right Daily|https://..." --neutral "Wire|https://..." --left "Left Daily|https://..."
   ```
2. Commit + push `feed.json` (the launchd nightly job does this automatically at
   midnight; or push manually).
3. GitHub Pages republishes; the bot posts to Discord within 5 min.

## Security model (no sign-ins)
- **No user accounts** → no credential storage, no auth attack surface.
- **Emails never stored by us** — the join form POSTs to a mail provider
  (Buttondown / Kit / Loops / Mailchimp). They handle PII, unsubscribe, GDPR.
- **Secrets never in this repo** — the Discord bot token lives in
  `rummy-bot/.env` (gitignored). Any future mailer key goes in GitHub
  *Actions/repo secrets*, used server-side only.
- **Branch protection** on `main` — only you push; consider requiring PRs.
- **GitHub Pages = GitHub's CDN** — DDoS protection + unmetered bandwidth free.
- **HTTPS enforced** by GitHub Pages by default.
- **Custom domain later**: add A/ALIAS records per GitHub docs + Enforce HTTPS.

## Join form
`index.html` has a placeholder `#join-form`. To activate, point its `action`
at your mail provider's form endpoint (or a tiny endpoint) — see the provider's
"embed a form" docs. No backend needed for option A (provider-hosted).

## Custom domain (optional, later)
In repo Settings → Pages → add `hey-dumb-dumb.com`; set DNS to GitHub's records;
enable "Enforce HTTPS".
